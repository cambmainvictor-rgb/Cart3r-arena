CART3R ARENA — version iPhone (PWA)

Pour l'installer comme une appli :
1. Publie le contenu de ce dossier sur un hébergement HTTPS (par exemple GitHub Pages).
2. Ouvre l'adresse du site dans Safari sur l'iPhone.
3. Appuie sur Partager, puis « Sur l'écran d'accueil ».
4. Valide « Ajouter ».

Important : iOS exige une adresse HTTPS pour l'installation PWA. Le ZIP seul ne s'installe pas comme une application.
Le jeu sauvegarde les trophées et l'Elo sur l'appareil (localStorage).
